# GoSaveTool for VS Code

Subtitles, images and text, fixed without leaving the editor. Everything runs on your computer: no file is uploaded and no account is needed.

Made by [GoSaveTool](https://www.gosavetool.com/), free online tools for creators.

## Subtitles: SRT and WebVTT

- **Convert SRT to WebVTT** and **WebVTT to SRT**: right-click an `.srt` or `.vtt` file, or use the editor menu **GoSaveTool**. The converted file is saved next to the original.
- **Shift subtitle timing**: move every cue earlier or later by any number of seconds (`1.5`, `-2`).
- **Repair and renumber**: sorts cues, fixes an end time before its start, removes overlaps and empty cues, and renumbers SRT.

Writing captions from scratch? The [VTT Subtitle Generator](https://www.gosavetool.com/vtt-subtitle-generator) times them against the video in the browser, and the [Auto Captions Generator](https://www.gosavetool.com/auto-captions-generator) writes them from speech.

## Images: compress, resize, convert to WebP

Right-click a PNG, JPEG, WebP, GIF or BMP in the Explorer and choose **Compress / Resize Image** or **Convert Image to WebP**. A panel shows the new size before you save:

- WebP, JPEG or PNG output
- quality slider with a live preview
- maximum width, keeping the aspect ratio
- the copy is saved next to the original; the original is never changed

More in the browser: [Image Compressor](https://www.gosavetool.com/image-compressor), [WebP Converter](https://www.gosavetool.com/webp-converter), [Convert Image Format](https://www.gosavetool.com/convert-image-format) and [Resize Image for Social Media](https://www.gosavetool.com/resize-image-for-social-media).

## Text: word count and case

- **Word and character count** in the status bar for the selection or the whole document, with reading time. Click it for sentences, lines and characters without spaces.
- **Change case**: UPPER, lower, Title Case, Sentence case, camelCase, snake_case, kebab-case.
- **Make URL slug**: `Ölçü Birimi & Çeviri!` becomes `olcu-birimi-ceviri`.
- **Clean extra spaces and blank lines**.

Need the limits of Instagram, X, TikTok or YouTube? See the [Character Counter](https://www.gosavetool.com/character-counter).

## Commands

Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and type **GoSaveTool**.

| Command | What it does |
| --- | --- |
| Convert SRT to WebVTT | Saves `name.vtt` next to `name.srt` |
| Convert WebVTT to SRT | Saves `name.srt` next to `name.vtt` |
| Shift Subtitle Timing | Moves every cue by N seconds |
| Repair and Renumber Subtitles | Sorts cues and fixes timing faults |
| Compress / Resize Image | Opens the image panel |
| Convert Image to WebP | Opens the image panel set to WebP |
| Word and Character Count | Full statistics of the text |
| Change Case… | Pick a case for the selection |
| Clean Extra Spaces and Blank Lines | Tidies the selection or document |
| More Free Tools in the Browser | Lists the tools on gosavetool.com |

## Privacy

The extension reads and writes only the files you run a command on. It sends nothing over the network; links to gosavetool.com open only when you click them. See the [Privacy Policy](https://www.gosavetool.com/privacy-policy).
