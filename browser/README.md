# GoSaveTool for Chrome and Firefox

Right-click any image to save it as **PNG, JPG or WebP**, or compress and resize it. Select text to count words and characters against X, Instagram, TikTok, YouTube and SEO limits. Everything runs in your browser; nothing is uploaded.

Made by [GoSaveTool](https://www.gosavetool.com/), free online tools for creators.

## Features

- **Save image as PNG / JPG / WebP**: right-click an image → GoSaveTool. Fixes the "WebP will not open" problem in one click.
- **Compress or resize image**: a page with format, quality and max width, showing the new size before you download.
- **Count words and characters**: select text → right-click. Shows words, characters, sentences, reading time and the limits of X (280), Instagram (2,200), TikTok (4,000), YouTube titles (100), SEO titles (60) and meta descriptions (160).
- **Text tools in the toolbar**: UPPER, lower, Title Case, Sentence case, slug, camelCase, snake_case and clean spaces.

## Permissions

| Permission | Why |
| --- | --- |
| `contextMenus` | The right-click entries |
| `downloads` | Saving the converted image |
| `notifications` | Saying when an image could not be converted |
| `storage` | Keeping the text of the toolbar box between openings |
| Access to sites (asked on first use) | Reading the image you right-clicked so it can be converted |

The extension sends no data anywhere and has no analytics. Links to gosavetool.com open only when you click them.
